# WordFinder

A **WordFinder** egy webes alkalmazás, amely segít szavakat keresni megadott betűk alapján. Hasznos lehet keresztrejtvényekhez, szókirakó játékokhoz vagy akár nyelvtanuláshoz is.

## Funkciók

- Magyar szavakat kereshetsz kattintással kiválasztott betűkből
- A találatok listája valós időben frissül
- Tiszta, minimalista felület
- Mobilbarát dizájn

## Használat

1. Kattints a képernyőn megjelenő betűkre a rendelkezésre álló karakterek közü
